# Bookmark Peeler

A Firefox add-on that removes or rewrites URL parameters when a bookmark is saved, using rules you configure.

**Status:** early development. See [docs/roadmap.md](docs/roadmap.md) for the plan and decisions, [docs/development.md](docs/development.md) for setup and packaging, and [docs/tests.md](docs/tests.md) for the automated and manual tests.
